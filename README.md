# Express Template

Starter project for the Unit 8 lessons.

To use it:

1. Click **Use this template** > **Create a new repository**, and give your repository a name.
2. In your new repository, click **Code** > **Codespaces** > **Create codespace on main**.
3. In the terminal, type `npm start`, then click **Open in Browser** when the pop-up appears.
4. To see the API, add `/api/hello` to the end of the address in your browser.
